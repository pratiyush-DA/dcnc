## 🔧 Implementation Details

### Classification Service

**Key Features**:
- Async/await for non-blocking operations
- Fresh fingerprint generation (no caching)
- Proper error handling and logging
- File validation (size, extension, encoding)

**Output Files**:

1. **good_data.csv**
   - Contains rows where ALL columns are good
   - Maintains original row structure
   - All columns included

2. **bad_data.csv**
   - Column-wise bad data details
   - Format: `column_name, row_index, original_value, workflow, subtype, method`
   - Useful for analysis and debugging

3. **reject_data.csv**
   - Rows where ANY column has bad data
   - Complete row rejection (entire record)
   - Original structure maintained

4. **fingerprint.json**
   - All column fingerprints
   - Includes: workflow, subtype, method, confidence, fingerprint data
   - Fresh per file (no caching)

### API Endpoints

**POST /api/v1/classify**
```json
{
  "file_path": "/path/to/file.csv",
  "has_header": true,
  "options": {
    "enable_validation": true,
    "enable_ml_clustering": true,
    "enable_ensemble_detection": true,
    "enable_llm_verification": false,
    "strict_mode": false
  }
}
```

**POST /api/v1/classify/upload**
- Multipart form-data file upload
- Query parameters for options
- Direct file processing

**Response Format**:
```json
{
  "status": "success",
  "job_id": "uuid",
  "files": {
    "good_data": "path/to/good_data.csv",
    "bad_data": "path/to/bad_data.csv",
    "reject_data": "path/to/reject_data.csv",
    "fingerprint": "path/to/fingerprint.json"
  },
  "statistics": {
    "total_rows": 1000,
    "good_rows": 950,
    "bad_rows": 30,
    "reject_rows": 20,
    "columns_processed": 36,
    "total_good_values": 34200,
    "total_bad_values": 1080
  },
  "metadata": {
    "processing_time": 12.5,
    "timestamp": "2026-01-27T10:00:00Z",
    "job_id": "uuid"
  }
}
```
